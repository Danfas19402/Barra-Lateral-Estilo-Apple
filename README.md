🍏 Barra Lateral Estilo Apple

Interface moderna inspirada no design clean, minimalista e elegante do ecossistema Apple.
Este projeto apresenta uma sidebar funcional, responsiva e com animações suaves, além de um dashboard intuitivo com cards de estatísticas.
